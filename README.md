# PredicGame

**Experimental Android applications for game statistics and multiplier analysis.**

Website: https://predicgame.com/

## About

PredicGame is an independent software development project focused on experimental tools for collecting game-round data, analyzing historical results, and testing statistical approaches.

## Applications

- **Aviator Predictor** — an experimental tool for studying multiplier history and testing analytical methods.
- **Lucky Jet Predictor** — an experimental tool for collecting historical results and exploring multiplier statistics.

## Development

Our development work includes Android applications built with Kotlin, WebView integration, JavaScript communication, data collection, and statistical visualization.

Historical results do not guarantee future outcomes. Experimental estimates are not guaranteed predictions, and past test results do not guarantee future performance.
